# NeoCobros Landing Page

Este repositorio contiene la Landing Page promocional y el simulador de la aplicación **NeoCobros**, la solución premium para la gestión de préstamos, control de cobros y planificación de rutas en tiempo real.

## Características de la Landing Page
- **Diseño Financiero Oscuro y Premium**: Estética moderna alineada con las aplicaciones SaaS de última generación.
- **Simulador Interactivo de Cuotas**: Permite calcular cuotas diarias, semanales o mensuales en base al monto e interés del préstamo.
- **Capturas Reales Anonimizadas**: Muestra la interfaz de usuario en acción preservando la privacidad.
- **100% Responsive**: Diseñado bajo una filosofía Mobile-First para garantizar una navegación perfecta en smartphones, tablets y ordenadores.
- **Optimizado para SEO**: Etiquetas meta optimizadas, semántica estructurada y tiempos de carga ultrarrápidos.

## Estructura del Proyecto
- `index.html` - Estructura semántica de la página.
- `styles.css` - Hoja de estilos con variables, transiciones y animaciones avanzadas.
- `script.js` - Lógica interactiva (menú móvil, simulador, acordeones).
- `assets/images/` - Capturas reales de la aplicación (anonimizadas gráficamente).

## Cómo Visualizar el Proyecto
Simplemente abre el archivo `index.html` en cualquier navegador web moderno, o utiliza una extensión como "Live Server" de VS Code para una recarga automática durante el desarrollo.
